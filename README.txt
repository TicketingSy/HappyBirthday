ROMANTIC BIRTHDAY WEBSITE — CUSTOMIZATION

1. Open index.html in a browser or publish the folder on GitHub Pages.
2. Homepage hero image is intentionally unchanged.
3. Add your own photo files in the images folder:
   - images/letter-photo.jpg  (photo beside the love letter)
   - images/memory-01.jpg through images/memory-08.jpg (Our Memories)
   Keep these filenames or update the matching src and data-full paths in index.html.
4. Add your MP3 file as audio/romantic.mp3.
   The site attempts autoplay when opened. Browsers often block audible autoplay;
   if blocked, the music starts on the visitor's first tap/click/key press. The Music
   control can pause or resume playback.
5. Keep index.html, style.css, script.js, images/, and audio/ together in the same folder.
